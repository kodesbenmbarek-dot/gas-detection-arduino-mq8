# Gas Detection System using Arduino Uno & MQ-8

## 📝 Overview
An embedded gas detection system designed to monitor Hydrogen gas levels using an **Arduino Uno** and an **MQ-8 gas sensor**. The system triggers visual (LED) and audible (Buzzer) alerts when gas concentration exceeds a predefined threshold and displays real-time status on an LCD screen.

## 🛠️ Hardware Components
- **Microcontroller:** Arduino Uno
- **Sensor:** MQ-8 Hydrogen Gas Sensor
- **Display:** I2C LCD (16x2)
- **Actuators:** Buzzer, LEDs (Red/Green)
- **Other:** Breadboard, Resistors, Jumpers

## 🚀 Key Features
- Continuous real-time gas level monitoring.
- Visual and audible alarm system upon gas detection.
- Real-time display status reporting.
- Modular C/C++ embedded code design.

## 📂 Project Structure
- `src/` : Contains Arduino C++ source code (`.ino`).
- `docs/` : Schematic diagrams and project documentation.
